# Portafolio Web — Johan Hawkins (Ing. Sistemas Junior)

SPA (Single Page Application) sin autenticación. Una sola página con secciones.

## Stack
- Frontend: React + TypeScript + Vite + Tailwind + Axios + React Query
- Backend: Node.js + Express + TypeScript + Prisma ORM + Zod
- DB: PostgreSQL (local → Supabase en producción)

## Buenas prácticas
- TypeScript estricto en frontend y backend
- Commits semánticos: `feat:`, `fix:`, `refactor:`, `style:`, `docs:`, `chore:`
- Ramas: `main`, `develop`, `feature/<nombre>`
- Separación de responsabilidades (controllers, services, routes)
- Zod schemas compartidos entre validación y tipos
